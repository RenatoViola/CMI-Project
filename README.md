# CMI-Project

## Repository Overview

A desktop multimedia browser and editor built with C++, openFrameworks, and OpenCV. It supports image and video browsing, visual filters, saved filter versions, related-media discovery, and webcam interactions including object-based search, face detection, and gesture selection.

See the [demonstration video](https://youtu.be/Ax0enjVV_KU) or [project report](Report.pdf) for a walkthrough.

---

## Controls

Use mouse clicks or taps for buttons and filter toggles. A webcam is required for the screensaver and camera features.

| Action | Mouse / Touch / Camera |
| --- | --- |
| Leave the startup screensaver | Move in front of the webcam |
| Browse images or videos | Drag / swipe horizontally across the corresponding carousel; release outside the central thumbnail |
| Open the selected media | Click / tap the central thumbnail |
| Apply visual filters | Toggle filters in the **GUI** panel; **ASCII** is available for images only |
| Save the current filter settings as a version | **SAVE** in the filter panel |
| Browse saved versions and related media | Click / tap the version icon below Home, then a thumbnail |
| Pause / resume a video | Click / tap the playback control over the video; its icon fades after use |
| Open the webcam view | Camera icon on the home screen |
| Toggle face detection | Face icon in the webcam view |
| Find media containing an object | Present the object to the webcam and click / tap the magnifying glass |
| Open a camera search result | Click / tap its thumbnail, or hold a closed fist in the corresponding top, right, bottom, or left area of the camera preview |
| Return to the home screen | Home icon |
| Return to the screensaver | Lock icon on the home screen |
